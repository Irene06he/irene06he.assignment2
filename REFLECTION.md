1. Explain the difference between flex-direction: row and flex-direction: column.
   The difference between flex-direction: row and flex-direction: column is :
   - row will make to each section on the same container from left to right
   - column will make to each section on the same container from top to bottom
2. Why is it important to use relative units (like %, vh, or rem) instead of fixed pixels (px) for
responsive design?
   It is important to use relative units instead of fixed pixels for responsive design
   because pixels is fixed value and it has to be changed mutually every time when adapting on
   different type of screen.
